# WALP 를 내 PC 에서 — Gemini 와 24시간 대화시키기

WALP 는 **LLM · 학습된 가중치 · GPU 없이** 도는 작은 대화 로봇이다. 이 묶음 하나로 내 PC 에서 돌리고,
Gemini(무료 호출)가 **사람 역할**로 WALP 와 몇 시간이고 대화하게 해서 WALP 가 대화로 자라는지 본다.

## 1. 준비 (한 번)

| 필요 | 확인 | 없으면 |
|---|---|---|
| Python 3.10 이상 | `python3 --version` | python.org 또는 패키지 관리자 |
| g++ · make | `g++ --version && make --version` | Ubuntu/WSL: `sudo apt install g++ make` · macOS: `xcode-select --install` |

- **Windows 는 WSL(Ubuntu) 안에서** 돌린다. 네이티브 Windows 는 확인하지 않았다(make 가 없다).
- macOS 는 확인하지 않았다 — `g++` 가 clang 이라 경고 규칙(`-Werror`)에서 멈출 수 있다. 멈추면 그 오류를 알려 달라.
- pip 로 깔 것은 **없다**(표준 라이브러리만 쓴다).

```bash
tar -xzf walp_only.tar.gz
cd walp_only
python3 -m walp.chat          # 처음 말할 때 C++ 코어를 한 번 빌드한다(수십 초). `안녕` · `파란 카드 찾아줘` · `끝`
```

## 2. 키 없이 배선 확인 (1분)

```bash
python3 -m walp.partner --fake --turns 30 --hours 1
```

마지막 줄에 `턴 30 · … · WALP 가 의도를 맞힘 …` 이 나오면 된다. (가짜 상대는 정해 둔 12문장을 되풀이한다 — 그 비율은 **외운 것**이지 진화가 아니다.)

## 3. Gemini 키

[Google AI Studio](https://aistudio.google.com/) 에서 API 키를 만든다. 둘 중 하나:

```bash
export GEMINI_API_KEY=여기에_키          # 이 터미널에서만
echo 'GEMINI_API_KEY=여기에_키' > .env   # walp_only/.env — 파일로(공유하지 말 것)
```

키는 요청 **헤더**로만 보낸다 — 로그나 URL 에 남지 않는다.

## 4. 24시간 돌리기

```bash
bash walp/run_partner.sh 24                      # 24시간, 배경에서(터미널을 닫아도 산다)
bash walp/run_partner.sh 24 --rpm 5 --rpd 500    # 무료 한도가 더 낮으면
bash walp/run_partner.sh 24 --model gemini-3.5-flash-lite
```

`started PID=… · log: …` 가 나오면 돌고 있는 것이다. 나오는 명령 그대로:

```bash
tail -f ~/.local/state/walp/partner.log     # 지켜보기 — 50턴마다 한 줄 요약
kill <PID>                                   # 멈추기
```

- **무료 한도**: 분당(`--rpm`, 기본 10)과 하루(`--rpd`, 기본 1000) 둘 다 지킨다. 간격 = max(60/rpm, 86400/rpd) — 기본값이면 약 86초에 한 턴,
  하루 약 1000턴. 모델마다 무료 한도가 다르고 바뀐다 — AI Studio 에서 보고 맞춰라. 넘으면(429) 알아서 쉬었다 다시 한다.
- 오류가 여덟 번 이어지면 멈춘다(키 · 모델 이름 · 망을 보라).

## 5. 무엇이 자라나

| 고리 | 어떻게 | 언제 적용 |
|---|---|---|
| 모르는 낱말 배우기 | WALP 가 모르는 말 → 상대가 쉬운 말로 고쳐 말함 → "혹시 'X' 를 Y 뜻으로?" → `네` | 서로 다른 페르소나 둘의 `네`(또는 `--write`) |
| 사례 기억 | WALP 가 되묻거나 틀렸을 때 상대가 자연어로 답·고침(Gemini 구동기는 `행위 <의도>` 를 쓴다) | 같은·비슷한 말에 곧바로(페르소나 둘 또는 `--write`) |
| 행동 진화 | **처음 한 번**, 그리고 고침·감사·불만이 **20개** 쌓일 때마다 배경에서 센서(성장망)와 행동(L0 반응 · L1 되묻기)을 새로 기른다(**약 40–60분 CPU** — 예전 성장망만일 때 약 7분) | **봉인 모음 관문**을 지날 때만 — 되풀이해 볼수록 엄격해진다(α 소비) |

**래칫**(챔피언–도전자): 자동 진화로 새로 기른 학습기를 언제 쓰나.
- 아직 승격본이 없으면 — 봉인 관문을 지나야 처음 승격한다.
- 승격본이 있고 **당신이 고친 말 가운데 떼어 둔 것이 5개 이상**이면 — 그 고친 말에서 지금 것보다 **더 많이 맞히고**,
  봉인 v5 에서 1%p 넘게 안 떨어지고, 손 규칙보다 못하지 않을 때 바꾼다. 봉인 관문(볼수록 엄격해지는 유의검정)은 이 길에서 요구하지
  않는다 — 사람 신호만으로는 거의 안 열리기 때문이다. 대신 이 교체는 **유의검정이 아니다**(알림에 "m승 n패(유의 아님)" 으로 적는다).
- 그보다 적으면 — 봉인 관문을 지나고 지금 것에 지지 않아야 바꾼다.
- 어느 쪽이든 못 바꾸면 지금 것을 그대로 쓰고 결과만 원장에 남긴다. 규칙과 한계: `walp/eval/PREREG_래칫_사용자기준.md`.

**Gemini 없이 기르기 — 형식 없이 말하면 된다**: `python3 -m walp.chat` 으로 평소처럼 말한다. WALP 가 헷갈리면
"혹시 **저에 대한 질문**, 아니면 **인사** 중 어느 쪽이신가요?" 처럼 되묻는다 — "저에 대한 거요" · "응 그거" · "아니 뒤에꺼" 처럼 편하게 답하면
그것을 원래 말의 뜻으로 배운다. 답이 틀렸으면 "아니 그게 아니라…" · "틀렸잖아" 처럼 말하면 다음 후보로 다시 묻는다.
(`행위 <이름>` 은 지름길로만 남았다.) 고친 말은 곧바로 기억 층이 쓰고, 신호가 20개 쌓일 때마다 행동 진화가 배경에서 돈다.
고친 말의 1/3 은 학습에 안 쓰고 래칫의 기준으로 떼어 둔다 — **고침을 약 15개** 주어야 사용자 기준이 켜진다.

**행동 기반(포섭) 구조(2026-09-30 봉인 v6)**: 분류기는 센서로 내려가고, 행동들이 한 턴에 모두 계산한 뒤 위 층이 아래 층의 말을 억제한다 —
L0 반응(답 틀을 직접 고름) · L1 되묻기(흔들리면 L0 을 억제하고 묻는다) · L2 기억(고친 말) · L3 숙고(여러 걸음 계획). 봉인 v6 에서
문장당 효용 0.85(예전 사슬 0.58, 26% 문장에서 되물음). 다만 되묻기의 **학습**은 확신 문턱 하나와 평균으로 같았다 — `walp/eval/PREREG_행동기반.md`.
손 규칙을 뺀 판은 봉인 v7 로 재는 중이다(`walp/eval/PREREG_손없는행동.md`).

**성장망이 무엇인가**: 진화(XCS)가 규칙 조건을 제안하고, 그 가운데 남은 오차를 줄이는 것만 은닉 단위로 붙는다(`walp/grownet.py`).
사전등록 실험(`walp/eval/PREREG_성장망.md`)에서 손 규칙만(50.7%)보다 크게 나았다(손+성장망 63.7%) — 그러나 **진화의 몫도 은닉층이 자라는
몫도 보이지 않았다**(은닉 단위 0~3개, 은닉 없는 회귀와 같음). 대화가 쌓여 자료가 달라지면 달라질 수 있다.

**여러 걸음 요청(숙고기, STRIPS)**: `선반은 피해서 파란 비자카드랑 열쇠 찾고, 없으면 검은 컵` 처럼 말하면 계획
`find(card,blue,visa,avoid=shelf) && find(key,avoid=shelf) || find(cup,black,avoid=shelf)` 을 세우고 같은 세계에서 걸음마다 시뮬한다
(`||` 는 앞 가지를 못 찾을 때만). 봉인 계획 모음에서 92.9%(여러 걸음을 거부하던 예전 36.3%). 약점: 거부해야 할 요청 6/25 에 계획을 세웠다.

**층 순서 · ESN(2026-09-30 봉인 v5)**: 학습기가 먼저 고르고(확신 ≥0.5) 모자라면 손 규칙 — 손 규칙 먼저보다 25승 1패로 나았다.
학습기에는 글자를 차례로 읽는 에코 상태 망(ESN)을 곁들인다(6승 0패).

## 6. 파일은 어디에

| 것 | 자리 |
|---|---|
| 대화 기록(턴마다) · 로그 · XCS 집단 · 알림 | `~/.local/state/walp/` (`WALP_STATE_DIR` 로 바꿀 수 있다) — `walp_partner.jsonl` · `partner.log` · `walp_xcs.json` · `walp_xcs_evolve.log` |
| 사용성 원장(모든 말 · 행위 · 고침 · 관문) | `walp_only/walp/usability/ledger.jsonl` |
| 배운 낱말 | `walp_only/walp/data/learned.csv` |

처음부터 다시 하려면 위 셋을 지운다.

## 7. 정직하게 알아 둘 것

- WALP 몸에는 가중치가 없지만, **이 대화로 쌓인 라벨은 Gemini(사전학습 LLM)가 단 것**이다. 원장에 `via=gemini` 로 남으므로
  나중에 사람의 대화만으로 다시 기를 수 있다.
- 페르소나 여럿은 **같은 LLM** 이다 — "서로 다른 둘" 규칙이 사람끼리일 때보다 약하다. 빠르게 하려고 `--write` 를 주면 LLM 의 실수도 바로 들어간다.
- 24시간 뒤 맞힘 비율이 올랐다면 그것은 **Gemini 상대에게** 나아진 것이다. 사람에게도 나아졌는지는 사람이 직접 대화해서
  (`python3 -m walp.chat`, 잘못 알아들으면 `행위 <이름>`) 재야 한다.
- 이 묶음은 WALP 만 담았다 — 디스코드 봇 · SE 도구(`도구 …`)는 없다.
