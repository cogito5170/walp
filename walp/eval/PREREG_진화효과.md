# 사전등록 — WALP 대화 행위: 진화 효과 입증 실험 (2026-09-30)

사용자: "3부터 해. 진화 효과 입증. 진화 효과 없으면 신경망 붙이자."

**이 문서는 봉인 모음 v3 가 도착하기 전에, 실험 코드를 돌리기 전에 커밋한다.** 무엇을 재고, 어떤 결과면 무엇을 하는지를
먼저 못 박는다. v3 는 **한 번만** 연다.

## 왜 이렇게 짰나

- 지금까지 세 번의 관문은 승격되지 않았고, 한 번(자동 진화 확인)은 보통 α 를 넘었지만 되풀이 보기로 무효였다. 봉인 v2 는 이미
  세 번 보았다 → **새 봉인 v3**(새 독립 에이전트, 약 320 문장 — 검정력을 위해 크게).
- "XCS: Is Covering All You Need?"(GECCO '24 Companion, doi 10.1145/3638530.3664146) — XCS 에서 **GA 를 끄고 덮기만** 써도
  배우는 경우가 있고, GA 는 규칙을 필요 이상 만들며 이득이 작거나 불안정할 수 있다고 한다. `[출처:조각]`
  → "진화 효과" 는 **GA 를 끈 XCS 와의 차이**로만 말할 수 있다. 그것이 H1 이다.

## 자료

- 학습: `dialog_act_train.tsv`(219) + `dialog_act_test.tsv`(v1, 177, 열림) + `dialog_act_test_v2.tsv`(v2, 183 — 합계를 세 번 보았으므로
  이제 학습 쪽) = 579.
- 시험: `dialog_act_test_v3.tsv`(봉인). 학습 글과 알맹이가 같은 문장은 v3 에서 빼고 그 수를 적는다(누수).
- 입력: 지금 WALP 와 같은 `dialog.입력()` — 손 단서 29비트 + 학습 579 에서 상호정보량으로 고른 글자조각 96.

## 조건 (씨앗 1..5 마다)

| 이름 | 무엇 | 가중치 |
|---|---|---|
| 손만 | 손 규칙(W0) | 없음 |
| 손+다수 | 손 규칙 빈자리를 학습 모음의 빈자리 최빈 행위로 | 없음 |
| NB | 베르누이 나이브 베이즈(같은 입력, 라플라스 1) — **진화 없는 단순 학습기** | 계수(W1) |
| XG | XCS + GA (지금 설정: 지도형 전체 갱신 · 60 epoch · N=1600) | 규칙(W2) |
| X0 | XCS, **GA 끔**(θ_GA=∞, 덮기·삭제만) — 같은 N · 같은 epoch | 규칙(W2) |
| NN | MLP 125→32(tanh)→12(softmax), 씨앗으로 무작위 초기화, SGD lr 0.05 · 60 epoch · 교차엔트로피. **사전학습 0 · GPU 0 · 표준 라이브러리** | 가중치(W2, 우리 자료로 처음부터) |

모드: `L만`(학습기 단독, 모든 문장에 argmax — 문턱 없음) · `손+L`(손 규칙 빈자리만 L 이 채움; XCS 는 실행 때와 같은 CONF=500,
NB/NN 은 사후확률 ≥ 0.5).

씨앗이 있는 학습기(XG · X0 · NN)는 문장마다 **다섯 씨앗 중 셋 이상이 맞으면 맞음**(다수결)으로 한 줄을 만든다. NB · 손만 · 손+다수는 결정적.

## 가설과 판정 (단측 부호검정, 문장별 짝, Holm 으로 네 검정 묶어 α=0.05)

- **H1 진화 효과(핵심)**: `XG만` > `X0만`. 그리고 씨앗 다섯 중 넷 이상에서 XG만 정확도 > X0만 정확도.
- **H2a 학습이 돕나**: `손+XG` > `손만`.
- **H2b 사소한 대조를 이기나**: `손+XG` > `손+다수`.
- **H3 진화가 단순 학습기보다 나은가**: `XG만` > `NB만`.

## 결정 규칙 (결과를 보기 전에 정한다)

1. H1 · H2a · H2b 가 모두 서면 → **진화 효과 입증**. 실행 관문은 그대로 XCS.
2. H1 이 안 서면 → 진화 효과 **입증 못 함**(사용자 지시대로 신경망을 붙인다): `손+NN` 이 `손만` 과 `손+다수` 를 **둘 다** 단측 부호검정
   p<0.05 로 이기면 NN 을 채움 자리에 붙인다. 못 이기면 **아무것도 붙이지 않는다**(손 규칙 + 사례 기억만).
3. H1 은 서는데 H2 가 안 서면 → "GA 가 덮기만보다 낫지만 WALP 에 쓸 만큼은 아니다" 로 적고 붙이지 않는다.

## 곁가지(기술만, 검정 없음)

- 학습 곡선: XG · X0 · NN 을 학습 25% · 50% · 100% 로(씨앗 다섯) — "대화가 늘수록" 의 모양.
- 씨앗별 정확도, 규칙 수, 시간.

## 사소한 설명과 그것을 죽이는 대조

| 사소한 설명 | 대조 |
|---|---|
| GA 가 아니라 규칙 수(용량)가 많아서 | X0 는 같은 N |
| 씨앗 운 | 다섯 씨앗 + 다수결 + 넷 이상 조건 |
| 진화가 아니라 특징(글자조각)이 일을 해서 | NB 가 같은 특징 |
| 학습 글이 시험에 새서 | 알맹이 같은 문장 제거 |
| 문턱(CONF)의 요행 | `L만` 은 문턱 없음 |
| 빈자리를 아무거나로 채워도 되는 것 | 손+다수 |

## 이 실험이 **못** 말하는 것

- 모음은 LLM 에이전트가 썼다 — 실제 사람의 말투에서 같을지는 모른다.
- 봉인 v3 를 연 뒤 실행 관문은 v3 로 옮기고 `BASE_LOOKS=1` 로 센다(이 실험이 첫 번째 봄).

## 결과 (2026-09-30, 봉인 v3 를 한 번 열었다 — `results/evolution_effect_v3.json`)

- **누수 102/326** — v3 문장 가운데 102 개가 학습 글과 알맹이가 같았다(대개 `네` · `ㅇㅇ` · `고마워` 같은 짧은 말). 사전등록대로 뺐고 224 로 쟀다.
  (빠진 것이 쉬운 말이라 손 규칙 정확도가 v2 보다 낮게 나온다: 53.1%.)

| 조건 | 정확도 |
|---|---|
| 손만 | 53.1% |
| 손+다수 | 56.2% |
| NB만 · 손+NB | **73.2%** · 67.4% |
| XG만 · 손+XG | 55.4% · 57.6% |
| X0만 · 손+X0 | 17.4% · 53.1% |
| NN만 · 손+NN | 71.4% · 67.9% |

| 가설 | 이김/짐 · p · Holm | 판정 |
|---|---|---|
| H1 XG만 > X0만 | 85/0 · 2.6e-26 · 씨앗 5/5 | **섬** — GA 는 덮기만보다 확실히 낫다 |
| H2a 손+XG > 손만 | 10/0 · 0.001 | 섬 |
| H2b 손+XG > 손+다수 | 10/7 · 0.31 | **안 섬** |
| H3 XG만 > NB만 | 5/45 · 1.0 | **안 섬 — 반대로 NB 가 크게 이긴다** |

학습 곡선(만, 씨앗 평균): XG 25% 57.6 → 50% 56.4 → 100% 57.0 (**자료가 늘어도 안 오른다**) · X0 24.7 → 29.5 → 24.7 · NN 66.8 → 69.6 → 72.5 (오른다).

**사전등록 결정 규칙 3번이 걸렸다: "GA 가 덮기만보다 낫지만 WALP 에 쓸 만큼은 아니다 — 붙이지 않음."** 신경망 규칙(2번)은 H1 이
안 설 때만이라 발동하지 않는다. 신경망(손+NN)은 손만 33/0 · 손+다수 31/5 로 크게 이겼지만, **이 결과를 보고 규칙을 바꾸면 사후
선택**이다 — 붙이려면 새 봉인 모음(v4)으로 다시 사전등록해 잰다.

읽는 법: "진화가 일한다"(H1)는 입증됐다. 그러나 **진화한 XCS 는 약한 학습기**다 — 셈만 하는 NB 에 45/5 로 지고, 자료가 늘어도
안 오른다. 진화의 효과는 '덮기만 하는 XCS' 대비일 뿐, WALP 를 낫게 하는 쪽은 NB · NN 이다.
