# 사전등록 — WALP 를 LLM 앞단으로 (2026-10-01, 코드보다 먼저 · 봉인 흐름을 열기 전)

사용자(2026-10-01): Opus/LLM 으로 가기 전의 얇은 층. Deliberative – Sequencing – Control. 먼저 스스로 해결하고
"모른다" 고 판단한 것만 LLM 의 답을 받아 **배운다.** 물건 찾기의 XCS 진화 구조를 그대로 옮긴다.
사용자 선택: LLM = **Claude API**(`claude-opus-5-5`), 배울 것 = **부류 + 답 저장 둘 다**.
선행조사: `paper/선행조사/WALP_LLM앞단.md` — Cache & Distil(ACL Findings 2024)이 뼈대가 같다. 새 방법이 아니다.

## 구조 (고정)

| 층 | 무엇 | LLM |
|---|---|---|
| **Control**(반응) | 행동 버스 그대로 — L0 반응(XCS) · 배움(가르친 뜻) · **답 캐시**(LLM 이 준 답, 새) · 기억 | 없음 |
| **Sequencing**(순서) | 이 턴을 어떻게 끝낼지 고른다: 스스로 답 · 여러 걸음 계획(STRIPS) 실행 · **위로 보냄**("모른다") | 없음 |
| **Deliberative**(숙고) | LLM 한 번 — 받은 말의 **부류**(12 행위 가운데 하나 또는 "그 밖")와 **답**을 JSON 으로 | Claude API |

"모른다" 의 판정(순서층, 고정): **(a)** 되묻기 층(L1)이 L0 을 억제하려 할 때(흔들림), 또는 **(b)** L0 이 고른 행위가
WALP 가 스스로 못 하는 것(바깥지식 · 범위밖)일 때 — **단 답 캐시가 이 말을 이미 덮으면 위로 보내지 않는다.**
LLM 이 없으면(키 없음 · 오류) 예전처럼 사람에게 되묻는다.

LLM 의 답에서 배우는 것:
1. **부류** — 원장 `kind=act_fix · via=llm` 라벨. 다음 진화에서 센서(성장망) · L0 이 배운다(일반화하는 쪽).
2. **답** — 원장 `kind=llm_answer`(그 말 · 부류 · 답 · 토큰). 답 캐시 행동이 글자조각 포함률 ≥ **θ=0.75** 이면 그 답을 다시 쓴다
   (가르친 뜻의 0.5 보다 엄하다 — LLM 답은 사실 질문이 많아 "프랑스 수도" 와 "독일 수도" 를 가르지 못하면 틀린다).
   다시 쓴 답 뒤에 불만이면 그 답의 θ +0.05.

## 재는 법 — 봉인 요청 흐름 + 신탁 LLM

`walp/eval/stream_v1.tsv`(독립 에이전트, 한 사람이 며칠에 걸쳐 보내는 요청 N≈400, **되풀이 · 같은 뜻 다른 말 · 새 뜻**이 섞임).
줄마다 정답 부류와 **답 묶음 ID**(같은 답이 맞는 요청끼리 같은 ID). 신탁 LLM = 그 줄의 정답 부류와 묶음의 대표 답을 돌려주고,
부른 횟수와 토큰(대략: 글자 수 기반)을 센다 — **실제 Claude 를 부르지 않는다**(비용 · 망). 그 한계는 아래에.

| 조건 | 무엇 |
|---|---|
| ALL | 모든 요청을 LLM 으로(기준선: 호출 100%, 신탁이라 틀림 0) |
| NOLEARN | 세 층, LLM 의 답에서 **안 배운다** |
| LEARN | 세 층, 부류 라벨은 흐름 중간 **두 번**(1/3 · 2/3 지점) 재진화로 반영, 답은 곧바로 캐시 |

지표: **LLM 호출 비율** · **스스로 답한 것 가운데 틀린 비율**(부류가 틀렸거나, 다시 쓴 답의 묶음 ID 가 틀림).

## 가설

- **H1** LEARN 의 호출 비율 < NOLEARN — 요청별 (부름 1/0) 짝 부호검정 단측 p<0.05
- **H2 비열등** LEARN 의 스스로 틀린 비율이 NOLEARN 보다 **2%p 넘게 높지 않다** — 차의 부트스트랩 단측 95% 위 한계 ≤ 0.02
- 결정: H1 · H2 둘 다 서면 배움을 켠다. H2 가 안 서면 답 캐시를 끄고(부류 학습만) 그렇게 적는다.

## 사소한 설명과 그것을 죽이는 것

| 사소한 설명 | 죽이는 것 |
|---|---|
| 흐름에 같은 말이 그대로 되풀이돼서 캐시가 이긴다(그건 정확일치 캐시면 되는 일) | **정확일치 캐시** 대조를 같이 잰다 — LEARN 이 그보다 나은 몫만이 겉 닮음 · 부류 학습의 몫 |
| 신탁이 늘 옳아서 배운 것이 늘 옳다 | 실제 LLM 은 틀리고 흔들린다 — 이 실험은 **배움의 배선 상한**이지 실사용 수가 아니다. 그렇게 적는다 |
| 토큰 절감 | 글자 수로 어림한 것 — 실제 토큰은 Claude 사용량 원장(`usage`)으로 실사용에서 잰다 |

## 수정 1 (2026-10-01, 봉인 흐름을 열기 **전**)

- "재진화" 는 **L0 만 다시 기른다**(학습 모음 + 그때까지 쌓인 LLM 부류 라벨). 센서(성장망)와 L1 은 기본 체계 그대로 둔다 —
  센서까지 다시 기르면 한 번에 40–60분이라 컨테이너 회수에 계속 끊긴다(v7 실측). 그만큼 부류 학습의 몫을 **덜** 잰다.
- 기본 체계 = 대화 모음 전부(학습 · v1–v7)로 한 번 기른 행동 기반 판, 씨앗 1 하나.
- 스스로 답한 것의 맞음: 답 캐시가 답하면 그 답의 묶음 ID 가 정답 묶음과 같을 때, 그 밖(틀 · 찾기)은 행위가 정답 행위와 같을 때.
- 흐름에는 사람의 불만 · 고침이 없다 — 문턱 조정(llm_tune)은 이 실험에서 일하지 않는다.

## 결과 (봉인 요청 흐름 v1, 한 번 열었다 · 2026-10-01 · `walp/eval/results/front_v1.json`)

400요청 · 기본 체계 씨앗 1 · LLM = 신탁(정답) — **배움의 배선 상한이지 실사용 수가 아니다.**

| 조건 | LLM 호출 | 스스로 틀림 | 토큰 어림 |
|---|---|---|---|
| ALL(전부 LLM) | 400 (100%) | 0 | 90,330 |
| EXACT(정확일치 캐시) | 173 (43.2%) | 33 (8.2%) | 40,161 |
| NOLEARN(세 층, 안 배움) | 195 (48.8%) | 33 (8.2%) | 45,273 |
| **LEARN**(세 층, 부류 + 답 캐시) | **153 (38.2%)** | 39 (9.8%) | 35,514 |

- **H1 섬** — LEARN 이 NOLEARN 보다 덜 부른다: 49 / 7, p=3.7e-9.
- **H2 안 섬** — 스스로 틀림 9.8% vs 8.2%, 차의 단측 95% 위 한계 +0.033 > 0.02.
- **결정(등록한 규칙): 답 캐시를 끄고 부류 학습만 켠다.** LLM 의 답은 원장(`llm_answer`)에 계속 남기지만 다시 쓰지 않는다.
- 대조: 정확일치 캐시는 LEARN 이 27번 더 안 부르고, EXACT 만 안 부른 것이 7번.

### 사후 관찰 (결정에 쓰지 않음 — 이미 연 흐름이라 새 봉인으로 다시 재야 한다)

- 재진화 없이 **답 캐시만** 켠 판: 호출 152 · 스스로 틀림 39 — LEARN(153 · 39)과 같다. **줄어든 호출과 늘어난 틀림이 전부 답 캐시에서
  왔고, L0 재진화(부류 학습)는 호출을 거의 못 줄였다**(이 흐름 · 씨앗 하나 · L0 만 재진화라는 수정 1 의 조건에서).
- 답 캐시는 43번 답해 37번 맞고 6번 틀렸다(14%). 틀린 6번은 전부 **이웃 묶음**(g018→g017 · g006→g005 · g014→g015 · g031→g030 ·
  g020→g019 ×2) — 흐름에 일부러 넣은 헷갈리는 짝으로 보인다. 겉 닮음(포함률 0.75)이 뜻의 차이를 못 가른다는, teach_v1 과 같은 한계다.
- 정확일치 캐시(EXACT)는 이 흐름에서 **틀림을 하나도 더하지 않고** 22번(195→173) 덜 불렀다. 배포를 정확일치로 바꿀지는 새 봉인 흐름으로
  재고 정한다(지금 바꾸면 연 자료를 보고 고른 것이 된다).
