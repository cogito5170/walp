# 사전등록 — WALP 대화 행위: 성장망(진화가 은닉 단위를 제안, RAN/CasCor 식으로 자람) (2026-09-30)

사용자: "성장망으로 지어. v4 봉인부터 진행해." 선행조사: `paper/선행조사/WALP_XCS결합_성장망.md`.
**이 문서는 봉인 v4 가 도착하기 전, 실험 코드를 돌리기 전에 커밋한다.** v4 는 **한 번만** 연다.

## 성장망(GROW) — 무엇을 짓나

- **출력층**: 소프트맥스 회귀(12 행동) — 입력은 [원래 특징 비트 125 + 자란 은닉 단위들]. SGD, 교차엔트로피.
- **은닉 단위 = RBF, 중심은 XCS 규칙의 조건.** 조건이 신경 쓰는 비트들과 입력의 해밍 거리 d 로 a = exp(−d). 딱 맞으면 1, 하나 어긋나면 0.37.
  (선행: X-NFCS 는 규칙=RBF. 우리는 규칙 조건을 **망의 은닉 단위 후보**로 쓴다.)
- **후보**: 학습 자료로 기른 XCS 집단의 규칙 조건(중복 제거). 조건 = 사람이 읽는 "이 글자조각/단서가 있고 저건 없다".
- **자라기(CasCor 식 고르기 + RAN 식 멈춤)**: 매 걸음 후보마다 "그 단위의 활성" 과 "출력층의 남은 오차(행동별)" 의 공분산 크기를 재어
  가장 큰 것을 붙이고 출력층을 몇 epoch 더 배운다. 학습 자료 안에서 떼어 둔 **검증 10%** 의 손실이 두 번 연속 안 줄면 멈춘다(상한 64 단위).
  → 자료가 늘수록 은닉층이 자랄 수 있다.
- **ESN 곁가지**: 글자를 차례로 읽는 에코 상태 망(저수지 100, 누설 0.3, 스펙트럼 반지름 0.9, 씨앗으로 무작위 고정). **출력 가중치만** 배운다.
- 모두 표준 라이브러리 · CPU · 사전학습 0.

## 자료

- 학습: train(219) + v1(177) + v2(183) + **v3(326, 이번에 열렸으므로 학습 쪽)** = 905.
- 시험: `dialog_act_test_v4.tsv`(봉인, 약 360, 흔한 상투어를 피해 쓰게 했다). 학습 글과 알맹이가 같은 것은 빼고 수를 적는다.
- 입력 특징: `dialog.입력()`(손 단서 29 + 학습 905 에서 MI 로 고른 글자조각 96).

## 조건 (씨앗 1..5; 씨앗 있는 것은 문장마다 다섯 중 셋 이상 맞으면 맞음)

| 이름 | 무엇 |
|---|---|
| 손만 · 손+다수 | 손 규칙 · 빈자리를 학습 최빈 행위로 |
| NB | 베르누이 나이브 베이즈 — **지난 실험의 1위(73.2%)** |
| LR | 소프트맥스 회귀, 은닉 0 — 성장망의 **자라기 전** 모습 |
| MLP | 은닉 32 고정(지난 실험의 NN 과 같음) |
| **GROW-GA** | 성장망, 후보 = **GA 로 진화한** XCS 집단의 조건 |
| GROW-X0 | 성장망, 후보 = **GA 끈**(덮기만) XCS 집단의 조건 — 진화의 몫을 가르는 대조 |
| ESN | 글자 저수지 + 출력만 |
| GROW-GA+ESN | 성장망 입력에 ESN 상태를 곁들임 |

모드: `L만`(모든 문장 argmax) · `손+L`(손 규칙 빈자리만, 사후확률 ≥ 0.5 일 때).

## 가설 (단측 부호검정, 문장별 짝, Holm 으로 다섯 묶어 α=0.05)

- **G1a**: 손+GROW-GA > 손만
- **G1b**: 손+GROW-GA > 손+다수
- **G2 진화의 몫**: GROW-GA만 > GROW-X0만 — 그리고 씨앗 다섯 중 넷 이상에서 정확도 GA > X0
- **G3 성장의 몫**: GROW-GA만 > LR만
- **G4 가장 센 기준선**: GROW-GA만 > NB만

곁가지(기술만): ESN만 · GROW-GA+ESN 대 GROW-GA · 학습 곡선 25/50/100%(정확도와 **자란 은닉 단위 수**) · 씨앗별.

## 결정 규칙 (결과를 보기 전에 정한다)

1. G1a · G1b 가 서고, GROW-GA만이 NB만에 **지지 않으면**(이김 ≥ 짐) → **성장망을 WALP 의 채움 자리에 붙인다**
   (실행 관문 대상이 XCS 에서 성장망으로 바뀐다). G2 가 서면 "진화가 은닉 단위를 고른다" 를, G4 가 서면 "NB 보다 낫다" 를 말한다.
2. 1 이 안 되고, 손+NB 가 손만과 손+다수를 **둘 다** 단측 부호검정 p<0.05 로 이기면 → **NB 를 채움 자리에 붙인다**(가장 단순한 것이 이겼다).
3. 둘 다 아니면 → 아무것도 붙이지 않는다.

## 사소한 설명과 대조

| 사소한 설명 | 대조 |
|---|---|
| 은닉층이 아니라 원래 특징이 일해서 | LR(은닉 0) |
| 진화가 아니라 후보가 많아서 | GROW-X0 — 같은 수의 후보 상한, 덮기만 한 집단에서 |
| 신경망이면 뭐든 된다 | MLP(고정 32) |
| 셈만 해도 된다 | NB |
| 씨앗 운 | 다섯 씨앗 + 다수결 |
| 누수 | 알맹이 같은 문장 제거 |

## 못 말하는 것

**결정 규칙 1 이 걸렸다 → 성장망을 채움 자리에 붙인다**(`dialog.LEARNER = "grow"`). 그러나 정직하게 읽으면: 검증 손실이

자료가 적을 때(25%) 은닉 단위가 더 붙었다 — 표본이 늘면 단위가 줄어드는 쪽이었다.

결과를 보고 나서 본 것(주장하지 않는다 — 새로 재야 한다):
- 모든 학습기에서 `손+L` 이 `L만` 보다 **낮다**(GROW 63.7 < 74.5). 손 규칙이 먼저 고르는 층이 이제 학습기를 끌어내린다.
- GROW+ESN 77.7% 가 가장 높았다(기술만 한 조건).
