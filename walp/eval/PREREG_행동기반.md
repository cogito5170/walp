# 사전등록 — 행동 기반(포섭) WALP (2026-09-30, 코드보다 먼저 · 봉인 v6 을 열기 전)

선행조사: `paper/선행조사/WALP_행동기반.md` — 가장 가까운 것은 Dorigo & Colombetti 의 행동별 LCS. **새 방법이 아니다.**
사용자 결정(2026-09-30): "이대로 지어".

## 구조 (고정)

모든 분류기는 **센서**로 내려간다. 행동은 센서 비트를 보고 **직접** 행위를 고른다.

| 센서 | 비트 |
|---|---|
| 겉 | `dialog.입력` (단서 · 파서 상태 · 겉모양 · 글자조각) |
| 성장망 | 예측 행위 one-hot 12 · 확신 ≥0.5 · ≥0.8 |
| 손 규칙 | 손 규칙이 고른 행위 one-hot 12 · 비었음 1 |

| 층 | 행동 | 학습 | 행위 | 억제 |
|---|---|---|---|---|
| L0 | 반응(ReactiveAnswer) | 자기 XCS(12 행동) — 고침은 전체 정보 갱신, 감사/불만은 밴딧 | 답 틀 하나를 골라 **실행** | — |
| L1 | 되묻기(Clarify) | 자기 XCS(2 행동: 통과 · 되묻기) — 결과의 효용이 보상 | "혹시 '…' 말씀인가요?" | L0 |
| L2 | 기억(Remember) | 없음(사례 기억 그대로) | 고친 말의 행위 | L0 · L1 |
| L3 | 숙고(Deliberate) | 없음(STRIPS 그대로) | 여러 걸음 계획 실행 | L0 · L1 · L2 |

- 모든 행동이 **같은 턴에 다 계산**하고, 억제 선(`상위 → 하위` 집합)이 버스에서 하위 출력을 지운다. 선은 자료(끊을 수 있다).
- L1 의 센서(불확실성): L0 XCS 의 최고 예측 칸 · 1·2위 차 칸 · 성장망 확신 칸 · 손 규칙과 성장망 일치 · 손 규칙 빔 · 파서 상태 · 길이 칸.

## 효용 (고정) — 모사된 사용자

정답을 답함 +1 · 틀린 답 −1 · 되물음 1−c (되물음은 **늘 풀린다고 가정** — 낙관적이다. 아래 D·E 가 이 가정을 견제한다).
주 비용 **c = 0.3**. 보고용 쓸기 c ∈ {0.1, 0.2, 0.3, 0.5, 0.7, 0.9} — 뒤집히는 c 를 표시한다.
XCS 보상 = 500·(효용+1) (0..1000).

## 학습 — 교차 적합(stacking)

학습 = 학습 모음 전부(train · v1 · v2 · v3 · v4 · **v5**). 2겹으로 나눠 센서(성장망)를 한쪽에서 길러 다른 쪽 비트를 만들고(OOF),
L0 도 2겹으로 길러 OOF 예측으로 L1 의 에피소드를 만든다. 마지막 L0 은 OOF 비트 전부로, 시험 때 센서는 학습 전부로 기른다
(시험 쪽 센서가 조금 더 자신 있다 — 알고 둔다). 씨앗 5 · 다수결. 봉인 v6 과 알맹이가 같은 학습 문장은 뺀다.

## 조건 (봉인 v6, 한 번 연다)

| | 무엇 |
|---|---|
| A 기존 | 지금 배포된 사슬(파서 → 학습기먼저(성장망+ESN, 확신 ≥0.5) → 손 규칙). 늘 답한다 |
| B 행동 | L0 + L1 + 억제 선 |
| C 선끊음 | B 에서 L1→L0 선을 끊음(= L0 만, 늘 답한다) |
| D 문턱 | L0 + 손으로 정한 되묻기: 성장망 확신 < θ 이면 묻는다. θ 는 학습 OOF 에서 효용 최대로 고른다 |
| E 늘묻기 | 늘 되묻는다(효용 1−c) |

(오프라인 모음에는 사례 기억·여러 걸음 계획이 없다 — L2·L3 은 이 실험에서 켜지지 않는다. 그들은 V5 검사로만 본다.)

## 가설 — 문장마다 효용 차의 짝 부호검정(단측), Holm(H1·H2·H3)

- **H1** B > C — 되묻기 행동과 억제가 효용을 더한다
- **H2** B > D — 학습한 되묻기가 조율된 문턱보다 낫다
- **H3** B > A — 행동 구조가 지금 WALP 보다 효용이 높다
- **N1** 답 정확도 C vs A: A>C 단측 p<0.05 면 "L0 이 지금 사슬보다 못하다" 로 본다(아니면 퇴행을 **못 찾은** 것 — 비열등 증명 아님)

## 결정 (먼저 적는다)

- H1 · H3 이 서고 N1 이 기각되지 않으면 → 행동 구조를 기본으로 배포(되묻기 대화 배선 포함).
- H2 가 안 서면 → "되묻기의 학습은 문턱 하나를 넘지 못했다" 로 적는다. 배포하더라도 L1 을 문턱으로 바꿀지 따로 판단한다.
- B ≤ E 이면(늘 묻기보다 못하면) → 답하는 쪽이 손해라는 뜻 — 배포하지 않는다.
- 어느 쪽이든 결과를 이 파일 끝에 그대로 붙인다(부정 결과 포함).

## 사소한 설명과 그것을 죽이는 것

| 사소한 설명 | 죽이는 것 |
|---|---|
| 되묻기가 싸서(c 작음) 이긴다 | E(늘묻기) · c 쓸기 — 뒤집히는 c 를 보인다 |
| 확신 문턱 하나면 되는 일 | D(OOF 로 조율한 문턱) |
| B 가 이긴 것이 L1 이 아니라 L0 이 좋아서 | H1(B vs C) — 같은 L0 |
| 센서가 학습 자료를 외워 OOF 가 무의미 | 교차 적합 · 시험은 봉인 v6 |

## 구조 검증 V1–V5 (사용자가 정한 다섯 — `tests/test_walp_behavior.py`, 끄고 켜기로)

- V1 행동이 직접 행위를 고른다: 옛 사슬(`dialog.고르기`)이 불리면 터지게 해도 버스가 답한다 · L0 의 행위를 바꾸면 답 틀이 바뀐다
- V2 보상이 그 행동의 가치만 바꾼다: L1 에 보상 → L1 집단만 변하고 L0 은 바이트 그대로(반대도)
- V3 억제가 실제로 일한다: 선 이음 → 상위 출력 · 선 끊음 → 하위 출력이 나온다
- V4 새 행동을 더해도 센서 · L0 을 다시 기르지 않는다: 더한 뒤 그들의 직렬화가 바이트 그대로 · 새 행동이 제 층에서 행한다
- V5 숙고층 · 기억층을 빼도 L0 이 모든 말에 답한다

## 수정 1 (2026-09-30, 스모크 뒤 · 봉인 v6 을 열기 **전**)

스모크(학습 자료 일부 100문장, 봉인 아님)에서 두 결함을 찾았다.

**(a) L0 이 자기가 읽는 센서보다 못했다.** 진단(같은 스모크 쪼갬, 씨앗 1): 성장망 센서 혼자 80%(반 자료로 기르면 75%)인데
L0 은 59–62%, **학습 자료 안에서도 73%** — 집단이 1599/1600 으로 차서 "성장망이 greet 라 함 → greet" 같은 규칙조차 못 굳혔다.
입력이 152 비트(단서 29 + 글자조각 96 + 센서 27)로 넓었다. → **L0 입력을 센서의 읽음 + 단서·파서 비트 29 로 좁힌다**(글자조각은
성장망 센서 안에서 이미 쓰인다). 같은 진단에서 L0 80%(성장망 80% · 기존 사슬 A 76%). 구조(행동이 직접 고르고 자기 보상으로 배움)는 그대로다.

**(b) 등록한 부호검정이 이 효용과 맞지 않는다.** 효용 차의 **방향**만 세므로, A 가 맞힌 문장에서 B 가 물으면(0.7 vs 1) 한 패,
A 가 틀린 문장에서 물으면(0.7 vs −1) 한 승으로 같게 센다. 스모크에서 B 는 평균 효용 0.81 로 A(0.52)보다 높았지만 부호로는 23승 35패였다.
→ **결정 규칙은 등록한 부호검정 그대로 둔다**(스모크를 보고 B 에게 유리한 쪽으로 바꾸는 것이므로). 대신 **보조 검정**으로 문장별 효용 차의
평균에 대한 짝 부호뒤집기 순열검정(단측, 20000번, 씨앗 0)을 같이 보고한다. 둘이 엇갈리면 엇갈린다고 적고, 배포는 등록한 규칙을 따른다.

스모크 수(학습 자료, 수정 전 L0): A 76.0% · L0 55.0% · 효용 B 0.806 · A 0.520 · D 0.723 · E 0.700 · B 물음률 58% ·
B 가 물은 곳의 L0 오답률 75.9% vs 안 물은 곳 2.4% · H1 44/14 · H2 25/2 · H3 23/35 · N1 23/2(기각).

- 한계: 효용은 **되물음이 늘 풀린다**는 낙관적 가정 위에 있다. 오프라인 모음에는 기억·숙고 층이 켜지지 않는다.
