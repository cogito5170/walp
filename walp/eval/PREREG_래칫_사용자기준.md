# 사전등록 — 래칫의 주 기준을 사람이 고친 말로 (2026-09-30, 코드보다 먼저)

사용자 결정(2026-09-30): "2번으로 지어" — LLM(Gemini) 상대 없이 사람과의 대화만으로 기른다.
그러면 래칫이 **봉인 v5(남이 쓴 말)** 가 아니라 **이 사용자가 고친 말**로 교체를 판단해야 한다.

## 규칙 (고정)

승격본(챔피언)이 **없을 때** — 바꾸지 않는다. 처음 승격은 예전 관문 그대로(봉인 v5 에서 손만·손+다수를 α_k 로 유의하게 이김).
사람 고침만으로 처음 승격할 수는 없다.

승격본이 **있고**, 떼어 둔 사람 고침이 **U_MIN = 5 개 이상**일 때 — 새 학습기(도전자)로 바꾸는 것은 셋 다 참일 때만:

| | 무엇 | 기준 |
|---|---|---|
| R1 주 기준 | 떼어 둔 사람 고침, 도전자 vs 챔피언 | 이김 **>** 짐 (비기면 안 바꾼다) |
| R2 가드레일 | 봉인 v5, 도전자 vs 챔피언 | 짐 − 이김 ≤ ⌈0.01·n⌉ (정확도 1%p 넘게 안 떨어짐) |
| R3 바닥 | 봉인 v5, 도전자 vs 손만 | 짐 ≤ 이김 (손 규칙보다 못하지 않음) |

- 도전자의 모드: 관문이 모드를 정했으면 그것, 아니면 챔피언의 모드를 물려받는다.
- 관문(α_k 유의)은 이 길에서 **요구하지 않는다**. 관문은 계속 재고 기록하며, 원장에 남는 xcs_gate 줄마다 봉인 v5 를 한 번 더 본 것으로 센다(α 소비는 그대로).

떼어 둔 고침이 **5개 미만**이면 — 예전 래칫 그대로(관문 통과 + 봉인 v5 에서 챔피언에게 짐 ≤ 이김).

## 기대 (먼저 적는다)

- 사람만 신호를 주면 관문(α_k)은 볼수록 엄격해져 **거의 안 열린다**. 예전 규칙으로는 첫 승격 뒤 교체가 사실상 멈춘다.
  새 규칙은 사용자 고침에서 나아지면 바뀐다.
- 대가: R1 은 유의검정이 아니다(떼어 둔 것 5개면 5승 0패여도 p=0.031 — 그보다 적으면 유의가 불가능하다). 교체는
  **운영 판단**이지 "나아졌다" 는 주장이 아니다. 그래서 알림·결과에 "사용자 고침 m승 n패(유의 아님)" 로 그대로 적는다.

## 이 규칙이 무효가 되는 조건

- 사람 고침이 한 사람 것뿐이면 R1 은 그 사람의 말투에만 맞춘다(목적대로이지만 일반화 주장은 아니다).
- 같은 떼어 둔 고침을 진화마다 되쓴다 — 여러 번 고를수록 그 문장들에 맞춰진다(되쓰는 떼어 둔 자료 문제, 선행조사 덧붙임).
- R2 는 퇴행을 **못 찾은** 것이지 비열등을 증명한 것이 아니다.

## 검사

5개 미만이면 예전 규칙을 따르는지 — 그리고 `진화()` 저장 길에서 상태 파일이 `승격: true` 로 실제로 바뀌는지.
